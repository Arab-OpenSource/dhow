## 4. السيرفر على Modular Monolith + دمج PR #1

**اللي اتعمل:**
- PR #1 اندمج في `main` بـ squash (`48836b1`)، بعد ما Sabry فعّل Dependency graph وكل الـ checks عدّت.
- السيرفر على `m1/server` اتبنى بالـ Modular Monolith بتاع Sabry، معمول على مقاس Go ([ADR-0030](../ADR/0030-server-modular-monolith.md)):
  - `App/`: تجميع الـ routes وتشغيل السيرفر.
  - `Config/`: البيئة وvalidator، وقاعدة البيانات، والـ logger.
  - `Core/`: Errors وResponse وI18n وMiddleware وEventBus.
  - `Database/`: الـ migrations والكود المتولّد من sqlc.
  - `Modules/System/`: فيه Routes وController وService وModels وQueries و`Test/`.
- الـ envelope فيه `Success` و`Data` و`Message` (مفتاح ترجمة) و`Meta` و`Error`، والحقول الفاضية بتتشال. أكواد الأخطاء بحروف كبيرة، والرسايل بتتترجم على السيرفر حسب `Accept-Language`.
- PostgreSQL 18 وuuidv7، والأعمدة الأساسية إجبارية، و`Instance` هو الاستثناء الوحيد.
- hooks جديدة ليها اختبارات (73 اختبار):
  - مكان الملفات وتسميتها.
  - اتجاه الـ imports، ومنع أي module يكلّم module تاني.
  - قواعد الـ migrations، ومنع `DELETE FROM`.
  - routes بـ kebab-case.
- validator v10.30.5 وtestify v1.12.1.
- إصلاح: عنوان IPv6 كان بيقبل أي port، ودلوقتي الـ port لازم يبقى رقم من 0 لـ 65535.

**قرارات Sabry:** الـ Modular Monolith بدل طبقات Go.md، وكل قواعد قاعدة البيانات والـ response مع تكييف Go، وvalidator وtestify، ودمج PR #1 بـ squash.

  - كل الاختبارات بـ `-race`.
  - govulncheck: مفيش ثغرات.
  - 73/73 hooks.
- `make build` عدّى.
- اختبارات Unit وIntegration وE2E وEdge عدّت على PostgreSQL 18 حقيقي في Docker.
- جرّبت الـ hooks الجديدة على حالات مخالفة، ورفضتها كلها.

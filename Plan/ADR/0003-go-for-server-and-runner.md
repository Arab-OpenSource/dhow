# ADR-0003: Go للـ control plane والـ runner

- **الحالة:** مقبول (مرحلة التصميم)
- **التاريخ:** 2026-10-27

## السياق
المنتج برمجيات بنية تحتية ذاتية الاستضافة. محتاج توزيع كـ binary واحد، واستهلاك ذاكرة منخفض، وتزامن (concurrency) قوي، ولغة جذّابة لمساهمي الـ DevOps. ولازم الـ runner والـ server يتشاركوا نفس الـ YAML parser ومُقيِّم CEL وكود البروتوكول.

## القرار
نكتب `apps/server` و`apps/runner` (وكمان الـ CLI) بلغة Go. واجهة الويب تفضل TypeScript، بأنواع (types) مولَّدة من OpenAPI.

## البدائل اللي اتدرست
TypeScript + Hono على Node (أنواع مشتركة مع الواجهة، لكن لغتين للـ backend وبيئة تشغيل أتقل)؛ Hono على Bun (سريع، لكنه أقل نضجًا للبنية التحتية الإنتاجية طويلة التشغيل)؛ NestJS (أتقل وفيه boilerplate أكتر).

## العواقب
binaries ثابتة (static) لكل المنصات و`packages/spec` مشترك. الفريق لازم يكون متمكّن من Go. مفيش مشاركة مباشرة للأنواع مع الواجهة (بنستخدم codegen بدلها).

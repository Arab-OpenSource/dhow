# ADR-0006: PostgreSQL افتراضيًا؛ وRedis اختياري

- **الحالة:** مقبول (مرحلة التصميم)
- **التاريخ:** 2026-10-27

## السياق
كل مكوّن إضافي بيحتفظ بحالة (stateful) بيصعّب الاستضافة الذاتية (التشغيل، النسخ الاحتياطي). Deploy Center كان محتاج MariaDB وRedis سوا.

## القرار
PostgreSQL هي قاعدة البيانات الوحيدة المطلوبة. وهي كمان بتخدم كـ job queue (`SKIP LOCKED`)، وخدمة الأقفال (advisory locks)، وناقل الأحداث (`LISTEN/NOTIFY`). Redis ممكن يتفعّل اختياريًا للـ pub/sub وحدود المعدّل (rate limits) على النطاقات الكبيرة. التخزين الكائني (S3/MinIO، أو القرص المحلي) بيحفظ اللوجات والـ artifacts.

## البدائل اللي اتدرست
Postgres + Redis إجباري؛ الإبقاء على MariaDB.

## العواقب
تثبيت ونسخ احتياطي أبسط. لازم نختبر المسارين: بـ Redis وبدونه.

# ADR-0009: الـ Plugins عبارة عن خطوات (steps) على شكل container image

- **الحالة:** مقبول (مرحلة التصميم)
- **التاريخ:** 2026-10-27

## السياق
منظومة خطوات قابلة لإعادة الاستخدام ضرورية. وتنفيذ كود طرف ثالث لازم يفضل جوه الـ sandbox.

## القرار
الخطوة القابلة لإعادة الاستخدام هي OCI image، بيتم الإشارة لها بالـ digest، ومعاها manifest بيعلن المدخلات والمخرجات بأنواعها (typed inputs and outputs). هيكون فيه registry مجتمعي بناشرين موثّقين (verified publishers) وتوقيعات cosign.

## البدائل اللي اتدرست
توافق جزئي مع GitHub Actions (سطح كبير وعبء توافق مستمر)؛ plugins بتقنية WebAssembly (المنظومة لسه غير ناضجة).

## العواقب
الـ plugins ممكن تتكتب بأي لغة، والعزل بيتورّث من الـ job. ممكن نعيد النظر في التوافق مع Actions بعد v1.0.

# ADR-0024: طرق التثبيت الرسمية

- **الحالة:** مقبول (مرحلة التصميم)
- **التاريخ:** 2026-10-27

## السياق
المستخدمين من VPS صغير واحد لحد عناقيد Kubernetes لحد الشبكات المعزولة (air-gapped).

## القرار
أمر واحد بـ Docker Compose (الافتراضي)، وHelm chart، وbinary واحد + systemd، وحزمة موقّعة للشبكات المعزولة (air-gapped signed bundle) ضمن Enterprise. أداة التثبيت بتولّد أسرار قوية، والسيرفر بيرفض الأسرار الوهمية (placeholders).

## البدائل اللي اتدرست
Docker بس.

## العواقب
أربع مسارات تثبيت للاختبار في CI. مسارات الترقية (upgrade paths) متوثّقة لكل واحد.

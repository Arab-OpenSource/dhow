# ADR-0008: Pipeline-as-code (`.dhow.yml`) مع محرّر مرئي

- **الحالة:** مقبول (مرحلة التصميم)
- **التاريخ:** 2026-10-27

## السياق
Deploy Center كان بيخزّن الـ pipelines كـ JSON بيتعدّل من خلال نماذج (forms). ده معناه مفيش مراجعة (review) ولا تاريخ (history) ولا diff.

## القرار
الـ pipeline عبارة عن ملف `.dhow.yml` جوه المستودع. المحرّر المرئي بيقراه، ويعدّل نموذج مكتوب بأنواع (typed model)، ويكتب الـ YAML من خلال pull request. الأحداث ذات الصلاحيات العالية (privileged events) بتقرا التعريف من الـ base branch. حماية البيئات (environment protection) تفضل على جانب السيرفر.

## البدائل اللي اتدرست
YAML بس (أصعب على المبتدئين)؛ تخزين في الواجهة وYAML جنب بعض (مصدرين للحقيقة).

## العواقب
مصدر واحد للحقيقة مع تجربة استخدام سهلة. المحرّر معتمد على تكامل الكتابة مع مزوّد الـ Git.

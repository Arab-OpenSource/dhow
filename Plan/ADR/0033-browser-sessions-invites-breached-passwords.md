# ADR-0033: جلسات المتصفح بـ cookie في السيرفر، والدعوات برابط وSMTP اختياري، وفحص كلمات السر المسرّبة

- **الحالة:** مقبول
- **التاريخ:** 2026-10-27
- **بيعدّل:** القسم 5 في `docs/security-model.md` (الـ access token والـ refresh token للمتصفح).

## السياق
الواجهة والـ API بيتخدموا من نفس الـ origin. وتصميم الـ JWT في الوثيقة كان بيشيّك على الـ `sid` في كل طلب برضه، يعني الجلسة كانت في السيرفر في الحالتين. والإشعارات كلها في M7، بس الدعوات محتاجة توصل في M2.

## القرار
- **جلسة المتصفح:**
  - cookie اسمها `__Host-dhow_session`: `HttpOnly` و`Secure` و`SameSite=Strict` و`Path=/`.
  - قيمتها 32 byte عشوائي، وبتتخزّن في `"Sessions"` كـ SHA-256.
  - المدة: idle timeout 12 ساعة، وabsolute timeout 14 يوم.
  - الـ ID بيتبدّل عند تسجيل الدخول وعند أي رفع في الصلاحيات.
  - الإلغاء فوري: بتسجيل الخروج، أو تغيير كلمة السر أو الـ MFA أو الدور، أو «اخرج من كل الأجهزة».
- **CSRF:** كل طلب غير GET لازم يكون فيه header `X-CSRF-Token`. الـ token مربوط بالجلسة، وبيتقرا من endpoint، والـ `Origin` بيتشيّك كمان.
- **الـ CLI والـ CI والتكاملات:** بيستخدموا API tokens (`dhow_pat_…`) بس، ومفيش JWT للمتصفح.
- **الدعوات:**
  - الأدمن بياخد رابط الدعوة ويبعته بنفسه.
  - لو SMTP متظبّط، الرابط بيتبعت بالإيميل كمان.
  - الـ SMTP ده نفسه هيتستخدم لاسترجاع كلمة السر.
- **كلمات السر المسرّبة:**
  - فحص Have I Been Pwned بـ k-anonymity، يعني أول 5 حروف بس من الـ SHA-1 بتخرج بره السيرفر.
  - بيحصل عند ضبط كلمة السر أو تغييرها، وشغّال افتراضيًا.
  - لو الخدمة مش متاحة، العملية بتكمل وبيتكتب تحذير في الـ log.
  - بيتقفل بـ `DHOW_BREACHED_PASSWORD_CHECK=false` للشبكات المعزولة.

## البدائل اللي اتدرست
- JWT قصير مع refresh token بيتغيّر: أعقد، والـ token بيعيش في JavaScript، وفايدته الوحيدة كانت للـ mobile، وده مش في الخطة.
- دعوات برابط بس: من غيرها استرجاع كلمة السر مش هيبقى متاح غير من الأدمن.
- فحص المسرّبة مقفول افتراضيًا، أو بقايمة محلية بس: تغطية أقل بكتير، وأغلب الناس مش هيفتحوه.

## العواقب
- الطلبات من الواجهة لازم تبعت الـ CSRF header، والـ client المتولّد هيضيفه أوتوماتيك.
- الـ load balancers لازم تحافظ على الـ cookies، ومفيش sticky sessions لأن الجلسة في قاعدة البيانات.
- `docs/security-model.md` هيتحدّث في نفس PR M2.1.

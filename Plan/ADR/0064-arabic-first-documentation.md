# ADR-0064: الوثائق العامة بالعربي أولًا ونسخة إنجليزي جنبها

- **الحالة:** مقبول. القرارات التلاتة خدها Sabry، والباقي مفوَّض.
- **التاريخ:** 2026-10-29
- **بيعدّل:** سطر «الوثائق العامة (بالإنجليزي) في `docs/`» في `CLAUDE.md`، وسطر «الإنجليزي بس جوه ... والوثائق العامة».
- **بيوسّع:** [ADR-0062](0062-simple-arabic-for-users.md) للوثائق العامة.

## السياق
- **الوثائق كلها إنجليزي:** `docs/` فيها حوالي 30 صفحة (التنصيب، والإعدادات، والـ runner، والأدلة، ونموذج الأمان)، وفي الـ root `README.md` و`CONTRIBUTING.md` و`SECURITY.md`. والعربي الوحيد هو `README.ar.md`، وهو مختصر ومتأخر عن الأصل.
- **الواجهة عربي أولًا، والوثائق لأ:** المستخدم بيلاقي الواجهة بالعربي المبسّط، ولما يدوس «اقرا الدليل» بيلاقي إنجليزي. ده عكس فكرة المنتج.
- **المشروع مفتوح المصدر:** فيه مساهمين ومنصّبين بره المنطقة العربية، ومحتاجين نسخة إنجليزي يعتمدوا عليها.
- **فيه كود بيقرا الوثائق:** `Config/EnvDocs_test.go` بيقارن جداول `docs/install/configuration.md` بالمتغيّرات، و`deploy/proxy-check/docs_test.go` بيقرا وثيقة الـ reverse proxy، والواجهة والـ installer فيهم روابط لصفحات معيّنة.

## المحاور اللي بتشيل القرار
- **الوصول للمستخدم:** الوثيقة لازم تتقري بنفس لغة الواجهة ونفس أسلوبها.
- **الصيانة:** نسختين معناها خطر إن واحدة تتأخر. لازم آلية تمنع ده، مش وعد.
- **الانتشار:** المشروع مفتوح المصدر، وحذف الإنجليزي بيقفله على المنطقة.

باقي المحاور (الأداء، والتكلفة، والترخيص) مش فارقة هنا.

## القرار

### المكان (قرار Sabry)
- **`docs/` بالعربي، وهي المرجع.** أي تغيير بيتكتب بالعربي الأول.
- **`docs/en/` بالإنجليزي، بنفس المسارات بالظبط:** `docs/install/compose.md` قصادها `docs/en/install/compose.md`.
- **أول سطر في كل صفحة رابط للنسخة التانية:** «English» في العربي، و«العربية» في الإنجليزي.
- **الـ root:** `README.md` و`CONTRIBUTING.md` و`SECURITY.md` بالعربي، وجنبهم `README.en.md` و`CONTRIBUTING.en.md` و`SECURITY.en.md`. و`README.ar.md` بيتشال لأن `README.md` بقى هو العربي. وGitHub بيعرض `README.md` العربي في صفحة الـ repo، وفيه رابط للإنجليزي في أوله.

### الأسلوب (قرار Sabry)
- **عربي مبسّط بقواعد ADR-0062:** فصحى بجمل قصيرة، ونفس جدول التبديل، ونفس الـ hook.
- **اللي بيفضل لاتيني:** كل code blocks والأوامر وأسماء المتغيّرات والملفات وحقول الـ API والاختصارات التقنية، زي ما ADR-0062 بيقول.
- **الـ code blocks متطابقة في النسختين حرف بحرف.** الكومنتات جوه أمثلة الـ shell أو YAML بتفضل إنجليزي، عشان المثال يتنسخ زي ما هو.
- **المصطلحات من `Plan/Glossary.md`.** أول مرة المصطلح يظهر في الصفحة، الإنجليزي بيتكتب بين قوسين: «جهاز التشغيل (runner)».
- **العناوين بالعربي.** الروابط اللي بتشاور على عنوان معيّن (anchor) بتتحدّث للعنوان العربي.

### النطاق (قرار Sabry)
- **جوه:** كل `docs/`، و`README` و`CONTRIBUTING` و`SECURITY`.
- **بره:**
  - رسائل الـ commits والـ PRs بتفضل إنجليزي بـ Conventional Commits.
  - الكود والـ identifiers.
  - `openapi.yaml`.
  - رسائل الـ CLI والـ runner.
  - `Plan/` بيفضل بالمصري المهذّب.

### منع التأخّر
1. **hook على `git commit`:** لو فيه ملف متغيّر تحت `docs/` (بره `docs/en/`) أو في الـ root من غير الملف المقابل في نفس الـ commit، الـ commit بيترفض ويقول الملف الناقص. والعكس كمان.
2. **فحص في `make check` (والـ CI):**
   - نفس مجموعة الملفات في النسختين.
   - نفس عدد العناوين على كل مستوى.
   - نفس الـ code blocks بالترتيب وبنفس المحتوى.
   - نفس عدد الجداول ونفس عدد الصفوف في كل جدول.
   - كل رابط داخلي بيشاور على ملف موجود في نفس النسخة.
3. **الـ hook بتاع العربي المبسّط (ADR-0062)** بيغطّي `docs/**/*.md` بره `docs/en/`، والملفات العربي في الـ root. وبيتجاهل الـ code blocks والـ inline code.

### الكود اللي بيقرا الوثائق
- **`EnvDocs_test` و`proxy-check/docs_test`:** بيقروا النسختين، لأن أسماء المتغيّرات والإعدادات لاتيني في الاتنين.
- **روابط الواجهة:** بتختار النسخة على حسب لغة المستخدم: العربي لـ `docs/`، والإنجليزي لـ `docs/en/`.
- **الـ installer و`doctor`:** نفس القاعدة. `Messages.Ar.go` بيشاور على `docs/...` و`Messages.En.go` على `docs/en/...`.

## البدائل اللي اترفضت
- **عربي بس:** أبسط في الصيانة، بس اللي مابيقراش عربي مش هيعرف ينصّب أو يساهم.
- **إنجليزي أساسي ونسخة عربي في `docs/ar/`:** العربي يبقى ترجمة درجة تانية، ودايمًا متأخّر عن الأصل.
- **أداة ترجمة أو i18n للوثائق (زي mkdocs-static-i18n):** اعتمادية جديدة ونظام بناء للوثائق، والـ repo بيتقري على GitHub مباشرة. فحص بسيط بيحقق نفس الهدف.
- **المصري في الوثائق:** أصعب على القارئ من بره مصر، ومش ماشي مع الواجهة.

## العواقب
- **كل تغيير في الوثائق بقى شغل مضاعف.** الـ hook والفحص بيخلّوه إجباري، مش اختياري.
- **`CLAUDE.md`:** سطر الوثائق، وقايمة الـ Markdown المسموحة في الـ root، وقايمة الـ hooks بتتحدّث.
- **`CONTRIBUTING`:** بيشرح القاعدة للمساهمين: اكتب العربي، أو افتح PR بالإنجليزي وحد من الفريق يكمّل العربي قبل الدمج.
- **روابط قديمة من بره** (issues أو مقالات) بتشاور على `docs/X.md` هتفتح العربي، وفي أوله رابط للإنجليزي.

# ADR-0010: البناء جوه Dhow أو استيراد الـ artifacts من CI خارجي

- **الحالة:** مقبول (مرحلة التصميم)
- **التاريخ:** 2026-10-27

## السياق
فيه فرق معندهاش CI. وفيه فرق تانية بتبني بالفعل في GitHub Actions أو GitLab CI.

## القرار
المسارين بينتجوا artifact معنوَن بمحتواه (content-addressed) وعمليات النشر (deployments) بتشير له بالـ digest. التكاملات الرسمية (GitHub Action ومكوّن GitLab CI) بترفع الـ artifacts وبتشغّل عمليات النشر.

## البدائل اللي اتدرست
بناء بس؛ استيراد بس.

## العواقب
الـ rollback بيعيد نشر artifact موجود ومبيعيدش البناء أبدًا. مسارين للاستيراد محتاجين اختبار.

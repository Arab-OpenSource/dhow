# ADR-0068: نطاق أول نسخة production

- **الحالة:** مقبول. القرارات الأربعة خدها Sabry، والباقي مفوَّض ومكتوب تحت.
- **التاريخ:** 2026-10-30
- **بيعدّل:** ترتيب ونطاق المراحل M3 لـ M11 في [`docs/roadmap.md`](../../docs/roadmap.md). ما بيلغيش أي قرار قديم: اللي اتأجّل بيفضل في الخطة بعد أول نسخة.

## السياق
- M1 وM2 خلصوا، وM3 خلص على Debian وUbuntu، وفاضل منه SELinux (ADR-0067) وKubernetes (M3.11) وgVisor (M3.8).
- الخطة الأصلية بتبني v1.0 كامل قبل أي استخدام حقيقي: أربع مزوّدين Git، وأربع أهداف نشر، والنسخ التجارية، والمحرر المرئي. ده وقت طويل جدًا قبل ما أي حد يستخدم داو.
- Sabry عايز يخلّص المنتج على الوضع الحالي ويبقى جاهز للـ production فعلًا، وبعدين يزود البيئات التانية.

## المحاور اللي بتشيل القرار
- **الوقت لأول استخدام حقيقي:** كل مرحلة بتتأجّل بتقرّب أول نسخة.
- **الأمان:** أول نسخة لازم تعدّي نفس معايير الأمان كاملة. اللي بيتأجّل هو المميزات، مش التحصين.
- **القيمة للمستخدم المستهدف** (ADR-0001): الشركات الصغيرة والمتوسطة والوكالات بتنشر على VPS وDocker، وده بالظبط اللي Deploy Center كان بيعمله.

## القرار

### قرارات Sabry
1. **البيئات المدعومة في أول نسخة:** أجهزة التشغيل على Debian وUbuntu بـ Podman rootless بس. SELinux (ADR-0067) وKubernetes (M3.11) وgVisor (M3.8) بعد أول نسخة.
2. **أهداف النشر:** SSH/VPS بإصدارات ذرية وفحص صحة ورجوع تلقائي، وDocker Compose. Kubernetes وStatic/CDN/SFTP بعدها.
3. **مزوّدي Git:** GitHub App، وGitLab، وGit عام بـ deploy key وwebhook (بيغطي Gitea وForgejo). Bitbucket بعدها.
4. **النسخ التجارية (M8) بعد أول نسخة.** أول نسخة production هي Community المجانية كاملة.

### المفوَّض (اقتراحي، والـ maintainer يقدر يغيّره)
- **M4 (خطوات النشر):** `.dhow.yml` بالـ schema والـ validator وCEL، وDAG وmatrix، والملفات الناتجة (artifacts)، والـ cache، وإضافات صور الحاويات، و`dhow lint`، وسياسة PRs من الـ forks. المزوّدين التلاتة بس.
- **M5 (الأسرار والبيئات):** زي الخطة كاملة: التشفير المغلّف وتدوير KEK، والأسرار المحدودة، والإخفاء، ومُصدِر OIDC للأحمال، والبيئات وقواعد الحماية والموافقات. ده قلب الأمان ومايتأجّلش.
- **M6 (أهداف النشر):** SSH/VPS وCompose، واستقبال الملفات الناتجة من CI خارجي بـ GitHub Action رسمية (ADR-0001 بيعتبرها من المخرجات الأساسية). مكوّن GitLab بعدها.
- **M7 (الواجهة):** مساحة العمل، ولوحات النشر، وعارض السجل، والموافقات، والإعدادات، والإشعارات بالبريد وwebhook وSlack وTelegram وDiscord (نفس اللي Deploy Center كان بيدعمه). المحرر المرئي، وTeams وWhatsApp، بعدها.
- **M3.13 (قفل M3):** fuzz ومراجعة تهديدات الـ runner plane والـ demo، على النطاق الحالي.
- **M9 (التحصين):** كاملة، وفيها مراجعة خارجية لمسارات الدخول واختبار اختراق خارجي قبل أي إعلان عام. ده شرط ما بيتأجّلش.
- **M10 (نسخة تجريبية عامة):** Compose والـ binary بالـ installer، وموقع الوثائق، وأداة استيراد Deploy Center v3. Helm بعدها.
- **M11 (GA):** زي الخطة.

### الترتيب
M3.13 ← M4 ← M5 ← M6 ← M7 ← M9 ← M10 ← M11. وبعد GA: SELinux، وKubernetes وHelm، وgVisor، وBitbucket، وStatic/CDN/SFTP، والمحرر المرئي، وM8.

## البدائل اللي اترفضت
- **الخطة الأصلية كاملة قبل أي نسخة:** شهور زيادة من غير أي مستخدم حقيقي.
- **نسخة أولية (MVP) من غير M5 أو M9:** أول نسخة لمنصة نشر من غير أسرار مشفّرة ومراجعة خارجية تكرار لنفس غلطة Deploy Center.
- **SSH بس:** أسرع، بس اللي شغّال بـ Docker هيستنى، وCompose شغله قليل فوق SSH.

# ADR-0037: تقسيم الواجهة لـ chunks بتتحمّل وقت الحاجة، وكتالوج الرسائل لجزئين

- **الحالة:** مقترح
- **التاريخ:** 2026-10-27
- **بيكمّل:** [ADR-0031](0031-web-structure-and-ui-components.md) (هيكل `I18n/Locales`) و[ADR-0032](0032-stacked-slides-and-themes.md) (الشرائح في الرابط).

## السياق
- `pnpm size` كان بيقيس 171 KB gzip من الـ JS الأولي، والميزانية 180 KB. وM2.2 لحد M2.4 هيضيفوا الـ MFA والـ passkeys وإدارة المؤسسة والفرق والـ tokens.
- الـ shell والشرائح والـ command palette وmotion وRadix كانوا كلهم في الـ chunk الأولي، حتى لصفحة الدخول.
- الكتالوج العربي والإنجليزي كانوا كاملين في الـ chunk الأولي (حوالي 10 KB gzip)، وكل نص جديد بيكبّرهم في اللغتين.
- السكربت كان بيعدّ الـ entry والـ modulepreload بس، وده ممكن يتلعب بيه.

## القرار
- **الـ routes:** الـ shell وصفحة الدخول وصفحة التنصيب بيتحمّلوا وقت الحاجة. `ShellGate` بيفضل في الـ chunk الأولي، و`AppShell` بيتحمّل بالتوازي مع `/me`.
- **الشرائح:** كل body وfooter لشريحة lazy جوه `Suspense`، والـ fallback هو `Skeleton`. الرابط اللي فيه `?stack=` بيحمّل الشرائح بتاعته مع الـ shell.
- **التحميل المسبق:** لما الماوس يقف على عنصر في القايمة أو ياخد focus، ولما الـ shell يرسم والمتصفح يفضى (`requestIdleCallback`).
- **الـ helper:** `lazyComponent` في `Core/Ui` فوق `React.lazy`، ولو الـ chunk اتحمّل قبل الـ mount بيرسم على طول من غير fallback. `lazyRouteComponent` بتاع TanStack للـ route components بس، لأن React 19 بيشتكي منه لو اتعلّق جوه الرسم.
- **الرسائل:**
  - `I18n/Locales/Boot/{Ar,En}.ts`: رسائل الشاشات اللي قبل الـ shell (الدخول، والتنصيب، والأخطاء العامة، والـ shell نفسه). بتتحمّل مع الـ chunk الأولي.
  - `I18n/Locales/Workspace/{Ar,En}.ts`: الباقي. بيتحمّل مع الـ shell للغة الحالية بس، وتغيير اللغة جوه الـ shell بيستنى الكتالوج التاني الأول.
  - `I18n/Locales/{Ar,En}.ts` فاضلين الكتالوج الكامل للأنواع والاختبارات، ومفيش كود إنتاج بيستوردهم.
  - اختبار بيمشي على الـ static imports من `Main.tsx` وصفحتي الدخول والتنصيب، ويتأكد إن كل مفتاح بيستخدموه موجود في `Boot`.
  - أي نص جديد لشاشة جوه الـ shell بيروح `Workspace`.
- **القياس:** `CheckSize.mjs` بيمشي على الـ static imports من `index.html`، وبيفشل لو فيه inline script أو style. الميزانية بقت الحجم الجديد زائد حوالي 10%.

## البدائل اللي اتدرست
- **كتالوج لكل module بيتحمّل مع الشريحة بتاعته:** أصغر، بس عناوين الشرايح والقايمة والـ palette بتستخدم مفاتيح من كل الـ modules، فهيبقى فيه تحميلات كتير وغلطات سهلة.
- **تحميل الإنجليزي بس وقت الحاجة:** بيوفّر للعربي، بس المستخدم الإنجليزي بيحمّل أكتر من الأول، والقياس الأسوأ مش بيتحسّن.
- **`manualChunks` لتقسيم المكتبات:** مش بيقلّل اللي بيتحمّل في الأول، بيوزّعه بس على ملفات أكتر.

## العواقب
- صفحة الدخول مش بتحمّل الـ shell ولا الشرائح ولا motion ولا Radix Dialog.
- أول رسم للـ shell بيستنى chunk الـ shell وكتالوج `Workspace`، والاتنين بيبدأوا بالتوازي مع `/me`.
- الرابط اللي فيه شريحة لسه بيشتغل بعد reload، والـ skeleton بيظهر لو الـ body لسه ما وصلش.
- أي مفتاح جديد بيستخدمه الدخول أو التنصيب لازم يتحط في `Boot`، والاختبار بيقول لو اتنسى.

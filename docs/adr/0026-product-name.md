# ADR-0026: Product name: Dhow

- **Status:** Accepted (design phase)
- **Date:** 2026-10-27

## Context
The new product needs a distinctive, trademarkable name that works as a CLI command and has regional meaning.

## Decision
Name the product **Dhow** (the traditional Arabian sailing ship, a word also known in English; it maps naturally to "ship it"). The CLI is `dhow`.

## Alternatives considered
Masar, Sahm, Wasl, Nashr, Falak, Marsa, Barq, Ankh, Nilo, Kemet.

## Consequences
**Pending:** trademark search and domain availability must be confirmed before public branding.

# ADR-0027: Public repository from day one

- **Status:** Accepted (design phase)
- **Date:** 2026-10-27

## Context
The project wants community participation early (build in public).

## Decision
The Dhow repository is public from the design phase. Sensitive material (vulnerability details about Deploy Center v3, private customer data) never goes into it. Vulnerabilities are reported via GitHub Security Advisories.

## Alternatives considered
Private until beta.

## Consequences
Early feedback and contributors. Roadmap and design are visible to competitors.

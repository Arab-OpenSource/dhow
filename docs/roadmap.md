# خريطة الطريق إلى أول نسخة production

الحالة: **مسودة**. الفريق: Sabry + Claude.

هذه الخطة تبني **أول نسخة production** من داو: نسخة Community المجانية كاملة، وآمنة بنفس معايير v1.0، وتعمل على البيئات الأكثر استخدامًا عند الشركات الصغيرة والمتوسطة والوكالات. الترتيب والنطاق من [ADR-0068](../Plan/ADR/0068-first-production-release-scope.md). المراحل مرتّبة، وكل مرحلة تنتهي بحالة تعمل ومختبَرة ويمكن عرضها. لا توجد تواريخ. الجهد مكتوب بمقاسات تقريبية (S < M < L < XL).

لم نُلغِ أي شيء تأجّل: كل البنود المؤجلة في قسم [بعد أول نسخة](#بعد-أول-نسخة)، وتبقى جزءًا من v1.0 الكامل.

## البيئات المدعومة في أول نسخة

- **أجهزة التشغيل:** Debian وUbuntu، مع Podman بلا root (rootless).
- **أهداف النشر:** SSH/VPS، وDocker Compose.
- **مزوّدو Git:** GitHub (App)، وGitLab، وأي Git عام بمفتاح نشر (deploy key) وwebhook، وهذا يشمل Gitea وForgejo.
- **النسخة:** Community فقط.

## بعد أول نسخة

هذه البنود من خطة v1.0 الكاملة، وتأتي بعد أول نسخة production بنفس معايير الأمان:

| البند | كان في | المرجع |
|---|---|---|
| أجهزة التشغيل على توزيعات SELinux enforcing (Fedora، وRHEL، وRocky، وAlma) | M3 | ADR-0067 |
| Kubernetes: مشغّل لأجهزة التشغيل (Pod مقيّد لكل تشغيل)، وHelm chart للسيرفر وأجهزة التشغيل، والتثبيت بـ Helm | M3 (M3.11) وM10 | ADR-0048 |
| gVisor كمستوى عزل اختياري | M3 (M3.8) | ADR-0043 |
| Bitbucket (Cloud وData Center) | M4 | ADR-0012 |
| أهداف النشر Kubernetes وStatic/CDN/SFTP | M6 | ADR-0011 |
| مكوّن GitLab CI لاستقبال الملفات الناتجة | M6 | ADR-0010 |
| المحرر المرئي لخطوات النشر (يكتب YAML ويفتح PR) | M7 | ADR-0008 |
| إشعارات Microsoft Teams وWhatsApp | M7 | ADR-0025 |
| **M8: النسخ التجارية:** ملف الترخيص + الاستحقاقات، وميزات `ee/` (SAML/SCIM، والأدوار المخصصة، وتعدد المراجعين، ونوافذ النشر، وHA، وcanary، وVault/KMS، وmicroVM، وSIEM، وحزمة بلا إنترنت). شرط الانتهاء: الميزات المدفوعة تعمل خلف الاستحقاقات، وانتهاء الترخيص يقلّل الميزات بهدوء | M8 | ADR-0017 |

**بعد ذلك:** لوحة التحكم المُدارة (ADR-0020)، والتوسع التلقائي لأجهزة التشغيل، وسجل إضافات مع ناشرين موثّقين، ومزوّد Terraform، ولغات أخرى.
